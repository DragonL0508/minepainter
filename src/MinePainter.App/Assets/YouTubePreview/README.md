# YouTube 縮圖預覽的週邊影片縮圖

小工具「小工具 → YouTube 縮圖預覽」裡，除了你自己的作品之外，版面上其他 17 格
影片用的就是這個資料夾的圖。

## 怎麼加圖

把原圖丟進 `_source\`，**檔名就是影片標題**（中文可以）：

```
_source\刷怪塔效率實測，五種設計一次比完.png
```

然後照常跑 `run.bat` 或 `publish.bat` 就好——兩支腳本建置前都會自動轉檔，
在這個資料夾產生同名的 `.webp`（480×270、q80，一張 15–35 KB），那才是進版控
與內嵌進 exe 的東西。要單獨轉也可以：

```
dotnet run --project tools/ThumbPack
```

原檔沒動過就不會重轉。直接丟在外層這格（不放 `_source\`）也行，轉檔時會先
被收進 `_source\`；丟已經是 `.webp` 的圖，尺寸不對會就地重轉。

`_source\` 有 .gitignore 擋著，原檔不進版控也不進 exe——直接內嵌 1920×1080 的
PNG 會讓 exe 肥好幾十 MB。**轉出來的 `.webp` 要記得 commit。**

## 其他

- 支援的原檔格式：`.png` `.jpg` `.jpeg` `.bmp`（`.webp` 直接放也可以）
- 16:9 最好；不是的話會置中裁切
- 建議 15 張左右。少於 17 張時同一張會在版面上重複出現（標題也一起重複）
- 這個資料夾沒有 `.webp` 時，週邊縮圖退回純色底，其餘功能照常
- 頻道名、觀看數、發布時間、影片長度不看檔案，是預覽網頁每次「重新整理」隨機配的
