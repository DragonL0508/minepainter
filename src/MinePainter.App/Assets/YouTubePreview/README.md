# YouTube 縮圖預覽的週邊影片縮圖

小工具「小工具 → YouTube 縮圖預覽」裡，除了你自己的作品之外，版面上其他 17 格
影片用的就是這個資料夾的圖。

## 放圖規則

- **檔名就是影片標題**，中文可以：`刷怪塔效率實測，五種設計一次比完.png`
- 支援 `.png` / `.jpg` / `.jpeg` / `.webp`
- 16:9 最好；不是的話程式會置中裁切
- 原尺寸隨便放，程式會縮成 480×270 的 WebP 再內嵌進預覽網頁
- 建議 15 張左右。少於 17 張時同一張會在版面上重複出現（標題也一起重複）
- 這個資料夾是空的時候，週邊縮圖會退回純色底，其餘功能照常

頻道名、觀看數、發布時間、影片長度不看檔案，是預覽網頁每次「重新整理」隨機配的。
