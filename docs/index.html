MinePainter

paint.net 風格的繪圖程式 · Windows

圖層、選取、文字、非破壞性效果堆疊、AI 去背 —— 解壓縮就能用。

下載 Windows 版 正在查最新版本…

解壓縮後執行 MinePainter.exe，不必安裝任何東西。 檔案比較大的話請耐心等一下（自包含版把 .NET 執行階段一起帶著）。

小顆版（需要 .NET 8）

電腦已經有 .NET 8 桌面執行階段 的話下載這個就好。

第一次開啟被 Windows 攔下來？

  • 這個 exe 沒有買程式碼簽章憑證，SmartScreen 會跳「已保護您的電腦」。
  • 點「其他資訊」→「仍要執行」即可。

系統需求

  • Windows 10 / 11（64 位元）
  • AI 去背功能需要另外下載模型（程式裡有引導）
