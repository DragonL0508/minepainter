# MinePainter 1.9.1：外部開圖修正與架構重構

### 這一版

- **修正外部開圖失敗**：從檔案總管或捷徑開啟大圖時，解析度模式對話框會等待主視窗顯示，避免「Cannot show window with non-visible owner」錯誤。
- **改善 4K 效果文字拖曳**：重用完整效果快照，減少按下瞬間停頓；修正快速連拖時的裁切、殘影重疊與過期結果寫回。
- **渲染與效果架構重構**：多層調整循序合成、效果來源快照、縮放貼圖重用與記憶體快取預算，減少重複運算。
- **遮罩收縮／擴張加速**：改善大半徑操作的效能。
- 928 項自動測試通過，保留既有文件格式與編輯流程。

GPU 首幀上傳與高背景負載仍可能造成短暫停頓；原本在畫布外被裁掉的效果內容，拖入後仍需放開重算。
