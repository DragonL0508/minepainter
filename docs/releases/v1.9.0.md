# MinePainter 1.9.0：架構重構

### 這一版

- **渲染架構重構**：多層調整改為循序合成，減少重複繪製，改善複雜圖層堆疊的效能。
- **4K 效果文字拖曳改善**：重用效果快照，減少按下瞬間的停頓；修正快速連續拖曳時的裁切、舊殘影重疊與過期渲染結果寫回。
- **更有效率的效果運算**：以來源快照縮短文件鎖定時間，重用效果預覽來源，跳過透明文字來源的不必要運算。
- **貼圖與記憶體管理改善**：重用縮放來源影像，依可用記憶體限制貼圖快取預算。
- **遮罩收縮／擴張加速**：大半徑操作不再隨半徑增加而反覆掃描鄰近像素。
- 加入實際 GPU 與 4K 文件拖曳基準；925 項自動測試通過。

這次更新保留既有文件格式與編輯流程。GPU 首幀上傳和高背景負載仍可能造成短暫停頓；原本在畫布外被裁掉的效果內容，拖入後仍需放開重算。
